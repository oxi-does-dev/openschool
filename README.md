# OpenSchool

Неофициальный клиент дневника МЭШ: Android-приложение, приложение для
рабочего стола (Linux и macOS) и терминальная утилита. Проект не связан с ДИТ Москвы, school.mos.ru и официальным
приложением МЭШ.

В репозитории нет cookies, токенов, идентификаторов ученика, ФИО, школы,
класса и других личных данных. Сессия МЭШ хранится только на устройстве,
где вы вошли.

## Что умеет

- день: уроки, перемены, кабинеты, учителя, темы, оценки, ДЗ;
- неделя: сводка (сколько заданий, контрольные, ЦДЗ, нагрузка по дням),
  уроки, оценки и ДЗ по дням, переход к дню и к заданию;
- домашние задания: материалы, файлы, ЦДЗ, фото работы, галочки
  «сделано / не сделано» и фильтр невыполненного;
- оценки: подробности, критерии, распределение по классу, рейтинг;
- итоги: средний балл с учётом веса, качество и успеваемость,
  распределение, динамика, статистика по предметам, калькулятор
  «что нужно до 3/4/5» и статистика домашнего задания;
- поиск по заданиям, предметам и комментариям к оценкам;
- тёмные темы: бумажная, Full black, Nord, Catppuccin, Gruvbox;
- уведомления о новых оценках и ДЗ (Android, без сторонних сервисов);
- цифровые домашние задания открываются внутри приложения;
- PDF-файлы рендерятся на устройстве, остальные открываются системой;
- офлайн-кэш дней, недель, оценок и ДЗ;
- вход через WebView на school.mos.ru или импорт cookies с ПК.

## Android

Приложение `OpenSchool` (пакет `ru.sch.diary` — историческое имя, чтобы
обновления ставились поверх без удаления данных). Android 8+, без Gradle
и AndroidX: обычный `Activity`, системный `WebView`, `HttpURLConnection`,
`org.json`.

APK собирается локально и в репозиторий не входит.

```bash
export ANDROID_HOME=$HOME/Android/Sdk
cd android
./build.sh          # -> android/sch.apk
./install.sh        # adb install + импорт cookies, если файл есть
```

Подробности: [`android/README.md`](android/README.md).

## Рабочий стол

Приложение `openschool` на Rust: окно рисует `egui`, без браузера,
Electron и локального сервера. Linux и macOS, Windows не поддерживается.
Запросы идут напрямую на school.mos.ru, cookies читаются из того же
файла, что и у терминальной утилиты. Экраны: день, неделя, домашние
задания, оценки по датам и по предметам, посещаемость, поиск, профиль.
По клику на урок открываются его подробности: тема, учитель, кабинет,
оценки, ДЗ, материалы и комментарии учителя.

```bash
cd desktop
cargo build --release
./target/release/openschool
```

Подробности: [`desktop/README.md`](desktop/README.md).

## Терминал

Утилита `sch` читает cookies Chromium, где вы уже вошли в school.mos.ru,
и ходит в официальный JSON API дневника.

```bash
sch today              # сегодня: уроки + ДЗ
sch today lessons      # только уроки
sch tmrw hw            # только ДЗ на завтра
sch +2 lessons         # послезавтра
sch 2026-11-10         # конкретный день
sch пт                 # ближайшая пятница
sch week [N]           # сводка на N дней вперёд
sch marks [N]          # оценки за N дней
sch dz                 # скачать материалы ДЗ в ~/DZ
sch profile            # кто я в МЭШ
sch login              # обновить сессию
sch doctor             # диагностика
sch serve              # локальный JSON API на 127.0.0.1:8787
sch help               # справка
```

Флаги:

- `--json`, `-j` — машинный JSON;
- `--raw-md`, `--md` — вывод в Markdown;
- `--no-md` — обычный текст без разметки;
- `--no-color` — без ANSI-цветов;
- `--no-download` — не скачивать материалы автоматически.

## Локальный API

```bash
sch serve
curl http://127.0.0.1:8787/day?date=today
curl "http://127.0.0.1:8787/marks?from=2026-10-23&to=2026-11-05"
curl http://127.0.0.1:8787/health
```

Сервер слушает только `127.0.0.1`. Наружу — только с `SCH_ALLOW_REMOTE=1`.

## Сборка C++

```bash
cd cpp
make -j4            # -> cpp/build/sch
make install        # -> ~/.local/bin/sch-cpp
```

Нужны C++20, libcurl, sqlite3 и OpenSSL. Python-версия осталась в
`sch.py` и `meshlib/` для сравнения.

## Структура

```
android/            приложение OpenSchool
desktop/            приложение для Linux и macOS на Rust
cpp/                терминальная утилита sch
meshlib/            прежняя Python-версия
sch.py              точка входа Python-версии
```

## Данные и приватность

- приложение и утилита только читают данные МЭШ;
- сессия не покидает устройство;
- нет аналитики, рекламы и сторонних SDK;
- cookies, токены, APK, keystore и сборочные артефакты исключены через
  `.gitignore`;
- если вы публикуете свой APK, используйте собственный ключ подписи и не
  коммитьте его.
