# OpenSchool Desktop

Дневник МЭШ для рабочего стола на Rust. Linux и macOS, без браузера,
Electron и веб-сервера: окно рисует `egui`, запросы идут напрямую на
`school.mos.ru` с этого компьютера.

## Что умеет

- день: уроки, перемены, кабинеты, учителя, темы, оценки, ДЗ;
- неделя: сводка (задания, контрольные, ЦДЗ, нагрузка по дням), дни лентой;
- домашние задания: актуальные и прошедшие, интервалы уроков, материалы,
  файлы, ЦДЗ;
- оценки: за 14/30/90 дней, вес, форма контроля, комментарии, шкалы 5/10/100;
- оценки по предметам: средний балл, место в классе, динамика, итоговые
  за период и цель, все оценки предмета с датами;
- подробности оценки: учитель, тема урока, критерии, распределение
  оценок по классу;
- посещаемость: пропущенные уроки по дням за 30/90/180 дней;
- профиль: учебный год, дата зачисления, школа, округ, директор,
  представители;
- поиск по заданиям, предметам и комментариям к оценкам;
- бумажная тема: светлая, тёмная или как в системе;
- переход к заданию и оценке по клику, подробности в отдельном окне;
- ЦДЗ открывается сразу на задании в браузере по одноразовой ссылке.

## Сборка

Нужен Rust (1.85+):

```sh
cd desktop
cargo build --release
./target/release/openschool
```

Linux: X11 или Wayland, OpenGL. macOS: сборка на macOS, готовый бинарник
под Intel и Apple Silicon собирается отдельно.

## Сессия МЭШ

Приложение не логинится само и не хранит пароль. Оно читает cookies,
которые уже сохранил существующий инструмент `sch`:

```
~/.cache/sch/cookies.json
~/.config/sch/cookies.json
~/Library/Application Support/sch/cookies.json
```

Можно указать свой путь в `SCH_COOKIES`. Обновить сессию: `sch login`,
затем кнопка «Перечитать cookies» в приложении.

## Безопасность

- cookies не пишутся на диск и не попадают в логи: только память процесса
  и заголовок запроса к `school.mos.ru`;
- в сообщениях об ошибках нет тела ответа и значений cookies;
- внешние ссылки открываются, только если ведут на `mos.ru` или его
  поддомены;
- приложение не слушает порты и не принимает входящие соединения;
- если файл cookies доступен другим пользователям, приложение предупредит:
  `chmod 600 ~/.cache/sch/cookies.json`;
- настройки — только выбранная тема, в `~/.config/openschool/settings.json`.

## Ограничения

- Windows не поддерживается;
- ЦДЗ открывается в браузере сразу на задании: приложение берёт у МЭШ
  одноразовую ссылку запуска, внутри окна тесты не проходятся;
- уведомлений о новых оценках пока нет.
