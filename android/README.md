# OpenSchool для Android

Нативное приложение-дневник МЭШ. Собрано из того же JSON API, что
использует терминальная утилита `sch`. Без Gradle и без AndroidX:
обычный `Activity`, системный `WebView`, `HttpURLConnection`, `org.json`.

Пакет `ru.sch.diary` оставлен историческим, чтобы обновления ставились
поверх без удаления данных.

APK собирается локально и в репозиторий не входит.

## Что умеет

- день: уроки, перемены, кабинеты, учителя, темы, оценки, ДЗ;
- листание дней, кнопка «Сегодня», выбор даты;
- дополнительные занятия и домашние задания;
- ДЗ: интервал урока, материалы, файлы, ЦДЗ, фото работы;
- оценки: подробности, критерии, распределение по классу, рейтинг,
  системы 5/10/100;
- ЦДЗ открывается внутри приложения в бумажной теме;
- PDF скачивается с сессией и рендерится на устройстве;
- остальные файлы открываются через `content://` системным приложением;
- офлайн-кэш дней, оценок и ДЗ;
- вход через WebView на school.mos.ru;
- импорт cookies из файла (SAF или папка приложения).

## Почему свой вход, а не cookies Chromium

Android изолирует приложения: прочитать профиль Chromium нельзя без root.
Приложение не трогает чужое хранилище, а получает свою сессию: cookies
живут в `CookieManager` этого приложения.

## Сборка

Нужны JDK 11+ и Android SDK (platform 35, build-tools 35.0.0):

```bash
export ANDROID_HOME=$HOME/Android/Sdk
cd android
./build.sh
```

Скрипт делает: `aapt2 compile` -> `aapt2 link` -> `javac --release 11` ->
`d8` -> `zipalign` -> `apksigner`.

Ключ подписи создаётся при первой сборке в `android/keystore/` вместе с
`password.txt` и исключён из git. Для публикации APK используйте собственный
ключ и не коммитьте его.

## Установка

```bash
adb install -r android/sch.apk
# или android/install.sh — установит и зальёт cookies, если они есть
```

Либо открыть `sch.apk` на телефоне и разрешить установку из неизвестных
источников.

## Первый запуск

Вариант 1 — войти в приложении: «Ещё -> Войти в МЭШ» -> страница входа
МЭШ -> логин mos.ru. После входа приложение само проверит сессию.

Вариант 2 — импорт cookies с ПК: «Ещё -> Импорт cookies» или файл в папке
приложения `Android/data/ru.sch.diary/files/cookies.json`. Формат:

```json
{"saved_at": 1762000000,
 "cookies": [{"host": ".school.mos.ru", "name": "aupd_token",
              "value": "...", "path": "/", "secure": true}]}
```

Файл содержит токен доступа. После импорта его можно удалить с телефона.
Сам файл и его содержимое в репозиторий не попадают.

## Приватность

- приложение только читает данные МЭШ;
- сессия хранится на устройстве;
- нет аналитики, рекламы и сторонних SDK;
- в репозитории нет cookies, токенов, ФИО, школы, класса и идентификаторов
  ученика.
